# Product Overview

Veyra is an AI-native execution and productivity platform. It is an independent
product with its own design and implementation; it is not derived from any other
existing productivity application.

## Vision

Help people plan and execute their work with a combination of:

- Reliable, deterministic planning and scheduling of work.
- An AI assistant that *proposes* actions, while the user (via deterministic
  rules) stays in control of what actually happens.

## Core principles

- **User owns the outcome.** AI suggests; the system validates and applies.
- **Predictability.** Scheduling and business rules are deterministic and
  explainable, not left to the whims of a language model.
- **Private by design.** No secrets or keys in the repository; configuration is
  environment-based.

## Status

Phase 1 is in progress. The first domain entity — a **Goal** (title, optional
description, status, priority, optional target date, owned by a development
user) — supports create, list, read, and update via the API and the web Goals
page. No AI, projects, tasks, scheduling, or authentication are implemented
yet. This document is a placeholder for the product vision and will be expanded
as features land.
